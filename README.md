# EduTutor

Веб-приложение для самостоятельного обучения с ИИ: предметы и темы,
теория, адаптивная практика, тесты с оценкой уровня, прогресс.

## Возможности
- Аккаунты студентов (Supabase Auth), у каждого своё дерево предметов и тем
- Теория: генерируется ИИ один раз, кэшируется для всех студентов
  (текст, SVG-иллюстрации, 4 разобранных примера, формулы KaTeX)
- Практика: новые задания каждый раз, адаптивная сложность 1–10,
  проверка хода решения ИИ с разбором ошибок, загрузка скрина с
  распознаванием рукописного решения, панель математических символов
- Тест: 20 заданий от лёгкого к сложному, без возврата назад, пропуск,
  секундомер, продолжение прерванного теста, итоговая оценка с уровнем
- Прогресс: время, решённые задачи, уровень усвоения, статусы тем
- Интерфейс RU/EN, цветовые гаммы (светлая/тёмная/системная),
  переносимая граница левой панели
- API-ключ Anthropic хранится зашифрованным (AES-256-GCM); учёт
  расходов, дневной лимит запросов (env DAILY_AI_LIMIT, по умолчанию 300)

## Настройка

### 1. Supabase — бесплатно
1. Создайте проект на https://supabase.com
2. SQL Editor → выполните по очереди ВСЕ файлы из папки `supabase/`:
   `schema.sql`, `schema_stage1.sql`, `schema_stage2.sql`,
   `schema_stage3.sql`, `schema_stage4.sql`, `schema_stage6.sql`
3. Authentication → Providers → Email → при желании отключите "Confirm email"
4. Project Settings → API: скопируйте Project URL и anon key

### 2. Переменные окружения
Скопируйте `.env.local.example` → `.env.local` и заполните:
- `NEXT_PUBLIC_SUPABASE_URL` — Project URL
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` — anon key
- `APP_SECRET` — любая случайная строка 30+ символов
- `DAILY_AI_LIMIT` — (необязательно) лимит ИИ-запросов в день на пользователя
- `ANTHROPIC_MODEL` — (необязательно) модель, по умолчанию claude-sonnet-5

### 3. Локальный запуск
```bash
npm install
npm run dev        # http://localhost:3000
```

### 4. Vercel (доступ из любой точки мира)
1. Загрузите проект в репозиторий GitHub (без `.env.local`!)
2. vercel.com → Add New Project → Import → добавьте те же переменные
   окружения → Deploy

## Использование
1. Зарегистрируйтесь и войдите
2. Меню слева → API-ключ → вставьте ключ Anthropic (console.anthropic.com)
3. Создайте предмет (Новый предмет +) или нажмите «Загрузить пример: Алгебра»
4. Тема → Теория / Практика / Тест. Прогресс — в меню слева

## Стоимость ИИ (ориентировочно, ключ пользователя)
- Теория: ~2–5 центов за новую тему (повторные открытия бесплатны)
- Практика: ~1–3 цента за задание с проверкой
- Тест целиком: ~$0.5–1
Счётчик расходов за 30 дней — в окне «API-ключ».

## Структура
- `app/` — страницы и API-маршруты (theory, practice/*, test/*, apikey)
- `components/` — Sidebar, TheoryView, PracticeView, TestView, ProgressView, модальные окна
- `lib/` — i18n, ai (вызовы Anthropic + учёт), crypto, theme, markdownMath
- `supabase/` — SQL-схемы по этапам
