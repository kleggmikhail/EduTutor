# EduTutor — Этап 0 (каркас)

Веб-приложение для обучения с ИИ. Этот этап включает: вход/регистрацию,
интерфейс в стиле Claude (левая панель + рабочая область), переключение
языка RU/EN, сохранение API-ключа Anthropic в зашифрованном виде с проверкой.

## Что нужно один раз настроить

### 1. Supabase (база данных и аккаунты) — бесплатно
1. Зарегистрируйтесь на https://supabase.com и создайте проект (New project).
2. В меню слева откройте **SQL Editor** → New query → вставьте содержимое
   файла `supabase/schema.sql` → **Run**.
3. В **Authentication → Providers → Email** при желании отключите
   "Confirm email" (чтобы сын мог входить без подтверждения почты).
4. В **Project Settings → API** скопируйте `Project URL` и `anon public key`.

### 2. Переменные окружения
1. Скопируйте `.env.local.example` в `.env.local`.
2. Вставьте URL и anon key из Supabase.
3. В `APP_SECRET` впишите любую длинную случайную строку (30+ символов).

### 3. Запуск локально
```bash
npm install
npm run dev
```
Откройте http://localhost:3000 — появится страница входа.

### 4. Публикация на Vercel (доступ из любой точки мира) — бесплатно
1. Загрузите папку проекта в репозиторий GitHub.
2. На https://vercel.com → Add New Project → выберите репозиторий.
3. В настройках проекта добавьте те же три переменные окружения
   (NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, APP_SECRET).
4. Deploy. Приложение получит постоянный адрес вида `edututor.vercel.app`.

## Как проверить Этап 0
1. Зарегистрируйте аккаунт (Sign up), войдите.
2. Слева меню: Выйти, Язык (переключение RU/EN), API-ключ,
   Новый предмет + и Прогресс (появятся на этапах 1 и 5).
3. Откройте «API-ключ», вставьте ключ Anthropic (sk-ant-...) → Сохранить.
   Приложение проверит ключ реальным запросом и сохранит его зашифрованным.

## Структура проекта
- `app/` — страницы (главная, /login) и API-маршруты
- `components/` — Sidebar, ApiKeyModal
- `lib/` — i18n (RU/EN), клиенты Supabase, шифрование (AES-256-GCM)
- `supabase/schema.sql` — схема базы данных с RLS-политиками
